# Evidencias S.A.P.I.
Registrar evidencia durante el trabajo, sin reconstruir hechos no observados.
Incluir segun corresponda: issue y objetivo; cambio implementado; archivos y revision real; comandos ejecutados y directorio; resultados y codigos de salida; artefactos; criterios de aceptacion cubiertos; impacto cientifico y limitaciones.
Separar hechos verificados, inferencias y verificaciones pendientes. Usar fechas reales y rutas existentes; nunca inventar hashes o resultados.
Excluir credenciales, tokens y datos privados innecesarios de registros. Guardar evidencia en la ubicacion que use el proyecto y enlazarla desde el informe cuando exista.
Para experimentos registrar dataset/version, corte temporal, configuracion, semillas pertinentes y procedimiento de reproduccion. Para UI registrar escenario y viewport si afectan el resultado.
Un informe breve basta para cambios pequenos. La plantilla orientativa es: Implementacion, Pruebas, Evidencia, Criterios verificados, Limitaciones.
